# Design context: valorant shop

Persisted project design context for better-web-ui skills. Source: creator-stated
preferences (not inferred from code).

## Audience
- Valorant players who use Discord daily, on desktop and mobile browsers.
- The creator plus their friends/community. Technically comfortable with
  Discord slash commands, paste-URL flows, and popups/tabs.

## Use cases (priority order)
1. Manage linked Riot accounts (add, remove, pick a main account). Most important.
2. Toggle daily DM alerts per account (shop, accessories) plus one global
   Night Market alert. All alerts default off.
3. Preview shops on the website (secondary; Discord commands are the main
   viewing surface): daily shop, accessory shop, Night Market per account.
4. Install the Discord bot (user-install "Add App" and server install).

## Brand personality
- Plain black and red Valorant style. Near-black surfaces, one red accent
  (#ff4655). No gradients-as-decoration, no glassmorphism, no purple/blue
  neon, no generic AI aesthetics.
- Compact and dense, but readable. Sharp corners (2-3px radius).
- Headings: Oswald, uppercase, letter-spaced. Body: Inter.
- Product name is "valorant shop", lowercase, everywhere user-facing.
- Voice: plain, direct, no em dashes anywhere, no emojis unless asked.

## Implementation defaults
- Plain HTML + vanilla CSS + vanilla JS served by Express (`website/`).
- No CSS framework, no build step. Shared version query (`?v=N`) for
  cache-busting static assets.
- Dark-only UI. System fonts fallback stack if Google Fonts blocked.
- Discord Components V2 for bot messages (flags 1<<15).
